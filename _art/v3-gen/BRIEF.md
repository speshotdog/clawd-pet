# 珍母點點 1.0 v3 素材生圖任務（給 Codex imagegen）

你是美術執行。用你內建的 imagegen 產圖，**不要改 src/ 裡任何檔案、不要 build、不要 commit**。
成品全部放進 `_art/v3-gen/`，最後寫 `_art/v3-gen/REPORT.md` 列出每個檔案、尺寸、你下的提示詞。

## 畫風（硬限制）
照這個遊戲既有的貼紙風：粗黑描邊、平塗色塊、少量奶油色高光、圓潤可愛，**沒有漸層、沒有寫實光影、沒有文字**。
先看參考：`src/clicker-icon-train.png`（哨子＋星星）、`src/clicker-icon-hand.png`、`src/clicker-bag-0.png`（零食包）。
背景一律透明（RGBA）。生完後用 Pillow 檢查：四角 alpha 必須是 0，主體置中，邊緣不能貼到畫布。

## 一、七個神器圖示（`clicker-art-<id>.png`，各 256×256，透明背景）
遊戲裡叫「神器」，是換桌布（重生）之後用印記買的永久加成。每個一個貼紙圖示：

| id | 名稱 | 效果 | 圖示點子（可自行改得更貼紙、更好認） |
|---|---|---|---|
| blessing | 收益祝福 | 全隊每秒收益 +10% | 金幣上長出四葉草 |
| tap | 攻擊力祝福 | 點擊拆包力 +10% | 一隻可愛的拳頭／肉球撞出星星 |
| skill | 技能祝福 | 技能效果量 +5% | 發光的魔法書或星星卷軸 |
| cd | 冷卻祝福 | 技能冷卻 −2% | 沙漏或碼表，帶一道加速線 |
| offline | 離線祝福 | 離線收益 +10% | 睡帽＋月亮＋小 z |
| chest | 寶箱祝福 | 寶箱包機率 +1% | 小寶箱，蓋子微開露金光 |
| dust | 粉塵祝福 | 換桌布多 1 顆萬用粉塵 | 一小撮閃亮彩色粉末／星砂 |

同一組要看起來像同一套：同樣的描邊粗細、同樣的配色彩度（參考哨子那張的紅／奶油／黃）。

## 二、寶箱包（`clicker-chest-bag-0.png`，448×512，透明背景）
遊戲的零食包偶爾會變成「寶箱包」（開出來獎勵 ×8）。現在只是把 `clicker-bag-0.png` 套 CSS 濾鏡變金色，要換成真的素材。
要求：**輪廓與構圖跟 `clicker-bag-0.png` 一樣**（同樣的鋸齒封口、同樣的位置與大小，之後要疊在同一個座標上），
但整包是金色／琥珀色的寶箱主題：包裝上的圓形圖案改成一個小寶箱＋閃光，封口可以加一條紅色緞帶或金色封蠟。
一樣沒有文字。生成後用 Pillow 把它跟 `src/clicker-bag-0.png` 的 alpha 外框疊起來比一下，外框差異太大就重生。
