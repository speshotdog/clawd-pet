## 構圖硬限制（照 seg1b，數字要量、寫進回報）

UI 會在中央垂直帶放 4 個關卡節點，所以：

- 把畫面 **y=[10%, 90%]** 切成四等分，每一等分內：
  - **左 35% 邊緣密度 ≥ 0.8%**、**右 35% 邊緣密度 ≥ 0.8%**（防止空白）
  - **中央 30% 邊緣密度 ≤ 1.2%**（中央只能是大面積、低對比的色塊，不要細碎裂紋、不要黑色輪廓線橫穿）
- 上下各 10% 是**接段過渡帶**：邊緣密度 0～0.3%，只放大面積純色。
- 量法：Y=0.2126R+0.7152G+0.0722B，NumPy gradient，幅值 hypot(gx,gy) > 24 的像素占比。

### 段與段要接得起來（這一輪新增）

地圖是五張由上往下直接相接（seg1 → seg2 → seg3 → seg4 → seg5），接縫處不能出現一條硬邊。

- `seg1-bands.txt` 有第一段上下 10% 帶的平均 RGB。
- **seg2 的上 10% 帶平均色**要接近 **seg1 的下 10% 帶平均色**（每個通道差 ≤ 18）；seg3 的上帶接近 seg2 的下帶，依此類推。
- 做法建議：在 prompt 裡寫明上帶要用的具體顏色（先量上一張的下帶再寫進下一張的 prompt），必要時對**上下 10% 帶**做平滑漸層銜接（只准動這兩條帶，不准用程式修改中間 80% 的插畫內容）。
- 所以請**照 seg2 → seg3 → seg4 → seg5 的順序**做。
- 每一個接縫的上下帶平均色差寫進回報。
