## 二、請回答這六題

### Q1. 第三套語言具體是什麼？請給 2～3 個**互相不像**的方向

不要給「深色科幻風」這種標籤。每個方向請寫出**可以照著做的規格**：

- 底（ground）：色、材質、有沒有紋理、紋理從哪來
- 字：字體家族取向、字級階梯、字距、數字要不要等寬
- 控制元件的**形狀語言**：邊角、邊框、按下的回饋形式
  （對照組：抽卡是 `clip-path:polygon(8% 0,92% 0,100% 50%,…)` 的六角切角＋`::before` 內縮 1px；
  1.0 是圓角 9px＋2px 描邊＋下方 2px 實心陰影）
- 版面的**結構語言**：網格、分隔、留白的規則
- 圖示的取向
- **一句話說它為什麼是「末世」而不只是「另一種深色」**

每個方向給一條**可量測的判準**，讓我能驗收「這確實是第三套語言，不是把抽卡那套換色票」。
**數值上下限成對。**

給出你的推薦，並說另外那些在什麼情況下才對。

### Q2.（**這一題最重要**）怎麼讓箔面精裝卡在新語言裡不像嵌入的廣告

這是你自己標的 C 最大風險。請具體回答：

1. **成因是什麼**？「新介面偏平面 → 卡像廣告」中間那一步到底是什麼在打架
   （材質密度？光源方向？色域？邊界處理？還是別的）——請講機制，不要講感覺。
2. **有哪幾種解法**？例如：讓 UI 也帶一點材質、給卡一個屬於 UI 的承載結構（框／槽／底座）、
   統一光源方向、讓卡的邊界與 UI 的邊界共用同一種收邊…你自己列。
   每種解法講清楚代價（會不會反過來稀釋掉「第三套語言」）。
3. **怎麼驗收**？我要能拿並排圖判定，不是口頭說。
   ⚠ 這條線的規矩：**視覺門檻一律上下限成對**，而且要交「開 vs 關」並排圖，並排圖沒差＝沒做到。
   請直接給我這一項的並排圖該怎麼拍、比什麼、門檻是多少。

### Q5. UI 語言跟「1.0 廢墟」地景怎麼共處
