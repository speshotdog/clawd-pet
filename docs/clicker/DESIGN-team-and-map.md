# 末世地圖 ＋ 編隊系統：需求釐清與設計起點

使用者原話（2026-09-10）：

> 我希望之後有編隊系統。最多帶 20 張卡片，神話 2、傳說上限 4、史詩 6、精良不限制
> （如果更高階的位置沒被占用，允許較低階級的插入）。
> 這樣隊伍系統加入後戰鬥力比較好評估，後面加新東西也不會膨脹太多。
> 技能 4 格，神話卡最多只能佔 1 格、傳說 1、史詩 1、精良 1，讓大家可以更合理搭配隊伍。
> （各一個是最大上限，不代表不能帶 3 張傳說 1 張史詩，或只放 4 張精良技能。**幫我理解我的需求**）
> 平衡度會是接下來開發最重要的部分。

---

## 一、編隊：你的規則可以寫成「累加上限」，而且比逐級上限更好用

「較高階沒占用就讓低階插入」這句話，等價於**前綴和**的四條式子：

```
神話                    ≤ 2
神話 + 傳說              ≤ 6      （2 + 4）
神話 + 傳說 + 史詩        ≤ 12     （2 + 4 + 6）
神話 + 傳說 + 史詩 + 精良  ≤ 20
```

四條同時成立就是合法隊伍。不用另外寫「遞補」邏輯——遞補是這組式子的自然結果：

| 隊伍 | 檢查 | 合法？ |
|---|---|---|
| 神話 2、傳說 4、史詩 6、精良 8 | 2≤2、6≤6、12≤12、20≤20 | ✅ 滿編 |
| 神話 0、傳說 6、史詩 6、精良 8 | 0≤2、6≤6、12≤12、20≤20 | ✅ 沒帶神話 → 傳說可以到 6 |
| 神話 0、傳說 0、史詩 12 | 0、0、12≤12 | ✅ 史詩可以吃滿前三層 |
| 精良 20 | 0、0、0、20≤20 | ✅ |
| 神話 3 | 3>2 | ❌ |
| 神話 1、傳說 6 | 1+6=7 > 6 | ❌ 神話占掉一格，傳說最多 5 |

**這個結構正好回答你說的「後面加新東西也不會膨脹太多」**——因為天花板綁在「格子」上不是綁在「卡」上。
以後出再多神話卡，能上場的還是 2 張；新卡只會改變「哪 2 張」，不會改變戰力上限。
這是對的直覺，值得寫死成不可動搖的規則。

## 二、技能：你的兩句話互相矛盾，我的理解是這樣

你先寫「神話 1、傳說 1、史詩 1、精良 1」，又說「不代表不能帶 3 張傳說 1 張史詩」。
這兩句**不可能同時成立**——如果傳說上限是 1，就不可能帶 3 張傳說。

用第一節那組累加式子套下去，只有一種讀法能讓你兩句話都成立：

```
神話技能                        ≤ 1
神話 + 傳說 + 史詩 + 精良（總格數）  ≤ 4
```

**也就是：唯一的硬上限是「神話技能最多 1 個」，其餘三階不設個別上限，自由填滿 4 格。**

驗證你自己舉的例子：

| 你說的組合 | 這個規則下 | |
|---|---|---|
| 3 張傳說 + 1 張史詩 | 神話 0 ≤ 1、總數 4 ≤ 4 | ✅ |
| 只放 4 張精良技能 | 神話 0 ≤ 1、總數 4 ≤ 4 | ✅ |
| 1 神話 + 3 傳說 | 神話 1 ≤ 1、總數 4 | ✅ |
| 2 張神話技能 | 神話 2 > 1 | ❌ |

所以我判斷你寫的「傳說 1、史詩 1、精良 1」是先列了一個想法，
接著在括號裡自己推翻了它。**如果我理解錯，這一條要先講清楚再開發**，
因為它決定整個平衡的形狀。

### ⚠ 但這個規則有一個立刻看得到的問題

如果只有神話被限制，那「4 個傳說技能」很可能比「1 神話 + 3 傳說」還強——
那樣神話技能就變成陷阱選項，跟你要的「更合理搭配」相反。

兩個可能的補法，**都不要現在憑感覺選，要用模擬器量**：

- **A：再加一條累加上限**，例如 `神話 + 傳說 ≤ 3`。這樣 4 傳說不合法，逼你混階。
- **B：不限制數量，改用格子成本**。例如神話技能佔 2 格、傳說 1.5 格……
  但這會讓「4 格」不再是整數直覺，通常不值得。

我的傾向是 A，理由是它跟編隊用同一套心智模型（累加上限），玩家只要學一次。

## 三、平衡怎麼量（你說這是最重要的部分，所以講清楚方法）

**不要用「算戰力數值」的方式做平衡，要用「讓策略互打」的方式。**
這條線先前踩過兩次同型的坑，兩次都是「數字看起來合理，實際玩起來爆炸」：

- 印記倍率從線性改開根號那次：**形狀不改，係數只是把爆炸延一天。**
- 輪迴倍率那次：**沒有輪迴策略的模擬器根本量不到問題。**

所以模擬器要能**自己組隊、自己打**，不是只把數字加總。要量的東西：

| 要量什麼 | 為什麼 | 判準要有上下限 |
|---|---|---|
| 最強隊 vs 中位隊的戰力比 | 差太多＝只有一種正解；差太少＝編隊沒意義 | 例如 1.4×～2.2×（實測後再定） |
| 前 20 名隊伍裡有幾種不同的組成 | 只有一種＝系統是假的 | ≥3 種 |
| 神話技能的採用率 | 太低＝陷阱選項；太高＝沒得選 | 例如 35%～75% |
| 每張卡在最佳隊裡的出現率 | 有卡永遠不會被選＝那張卡是死的 | 每張 >0 |
| 新增一張神話卡後戰力上限的變化 | 這是「膨脹」的定義 | 例如 ≤3% |

**最後一列是這整套設計的驗收條件**——你要的「後面加新東西也不會膨脹太多」
必須是一個跑得出來的數字，不然沒人知道有沒有做到。

## 四、末世地圖：這份還沒開始設計，先列要先決定的事

在畫任何地圖之前，有四件事會決定地圖長什麼樣，建議先答：

1. **戰鬥是自動還是有操作？** 決定技能格的意義（自動＝配隊即結果，模擬器好寫；
   有操作＝技能是主動技，平衡要另外算）。
2. **地圖是線性關卡還是可自由選路？** 決定「編隊」是一次決定還是每關可換。
3. **失敗的代價是什麼？** 沒有代價的話玩家會用最強隊硬撞，編隊的意義會消失。
4. **跟現有的點擊本體怎麼接？** 珍母點點現在是放置點擊，
   末世地圖是要吃同一份資源（粉塵／印記），還是自成一套？
   吃同一份的話，前面那條「不會膨脹」的規則必須同時管住兩邊。

⚠ 現有的第七站就叫「滅世都市」，`boss-city` 徽章也已經存在。
**要先確認「末世地圖」是要擴充它，還是另開一個新模式**——這會改變所有後續設計。
