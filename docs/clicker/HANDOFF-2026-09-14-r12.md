## 這一輪做了什麼

### 1. 收藏卡改成原生渲染（最大的一塊）
以前收藏卡是塞一個 iframe 去嵌 `src/apoc/mohuashaonv.html`（10.5 MB 的獨立頁）。
那條路是**模糊、掉 FPS、字型不對**三個抱怨的共同根因：150px 寬的 iframe 會用 150px 的
版面視口算版再放大。2.0 的 71 張卡從來不走那條路，所以「2.0 正常、1.0 很醜」。

現在走 `ClickerHolo.face()`，跟那 71 張**完全同一段程式**：
- `src/apoc/collect.js`（產生檔，別手改）＝ 卡資料＋素材對照＋`special` 階級註冊
- `src/apoc/collect-face.js` ＝ 獨立頁在 `create()` 之後做的加工（兩層特殊反光、替身動作、16 顆愛心）
- `src/apoc/holo-special.css` ＝ `.r-special`（共用的 holo.css 沒有這個階級）
- 抽取器 `tools/apoc/build_collect_card.py`（來源是使用者桌面那份「魔花少女卡面莓紫.html」）
- `src/apoc/mohuashaonv.html` 與 `tools/apoc/import_collect_card.py` 已刪除

收藏卡頁也重排成展示櫃（左卡右說明牌），直式改直排。

### 2. 地圖回顧 ＋ 全破常駐怪
走過的站可以無限重打：`a.revisitAt`（整數/null）＋ `stage.revisit`＋`stage.farm`。
拿那一站的錢、**進度不動**。全線通行之後靠同一條路在場上常駐一隻，不要空著。
王關打到一半不能落跑（不然跑一趟地圖就能躲掉 60 秒判輸）。

⚠ 踩過的坑：怪打死後有 1 秒重生空檔，那一秒 `autoFight` 會掉下去打「目前站」，
回顧模式一秒自我取消、進度一路暴衝（實測 8 → 19）。所以 revisitAt 分支一定要直接 return。

### 3. 星數改 A 版（參考薑餅人王國）
格子**永遠 5 個**，1～5 亮金星、第 6～10 星把金星從左邊一顆顆換成寶石星。
卡位只有 90px 寬，10 顆 13px 的星要 140px，本來就塞不下。
寶石星＝半透明水晶，產生器 `tools/apoc/make_gem_star.py`（amethyst / aqua / ruby 三色，現用 amethyst）。
順帶修掉神話那排彩虹底的 `mix-blend-mode:luminosity`——它會把星星顏色整個吃掉。

### 4. 修掉的回報
- **放棄進度沒拿到印記**：`cleanupPage()` 的「從零開始」只帶 settings／legacy／收藏卡，
  印記／神器／祝福／輪迴次數全歸零。現在照帶。
  ⚠ 連帶：買過 `markShop.slot4` 的話 validate 要求 `skillSlots` 長度 4，`fresh()` 只給 3 → commit 失敗、
  按鈕按下去毫無反應。已補。
- **手機存檔頁遮擋**：面板底部留白不足（「檢查」鍵離螢幕只剩 3–4px，壓在虛線內框上）
  ＋ 徽章牆 `repeat(5,1fr)` 的 `1fr` 最小值是內容寬度不是 0，64px 的徽章把整排擠出畫面。
- **打王時王不會動**：根因是 `clicker.css` 開頭一條 `#game * { animation-duration:.01s !important }`，
  手機開省電模式就會觸發。角色逐格動作現在減速一半而不是停掉。
  ⚠ 因為那條是 `!important`，後面每張卡各自寫的 `animation:none` **從來沒生效過**。
- **「單抽很虧」**：只有付金幣那一抽才漲價，用券不算——以前只寫在 tooltip。
  順帶修掉有券時會印出「下一抽 0」的錯誤（`drawCost1` 有券會算成 0，新增 `drawCostNext`）。

### 5. 工具鏈
- `tools/export-web.py` **本來只複製、從不刪除**：src 裡刪掉的東西會永遠留在 `dist-web` 一路被部署出去
  （實例：退役的 10.5 MB 獨立頁還在線上下載得到）。現在會清殘留。
- 同一支的防快取 `?v=` 用 `git rev-parse HEAD`，**工作區髒的時候 HEAD 沒變**，
  等於做出「新 HTML 配快取裡的舊 JS」。現在髒的時候改用 css/js 內容雜湊（`wip` 開頭）。
- `tools/apoc/build_fonts.py` 的字集要掃 `collect.js`／`collect-face.js`／`holo-special.css`，
  不然「魔花少女」「特殊」會掉進 fallback 字型。已加上「卡面必備字」的明確檢查。
