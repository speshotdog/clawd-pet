# 珍母點點 1.0 數值 v3：牆、編隊、有限印記、派遣（2026-09-12 起草）

上一版：`DESIGN-balance-v2.md`（2026-09-07）。本版的起因是使用者截圖收益祝福 Lv.1462（×147）、
以及 Sakura Clicker／Clicker Heroes 逆向（`REFERENCE-2026-09-12-sakura-clicker.md`）。
每一條先寫**為什麼會變好玩**，再寫規則；使用者原話：「要真的理解為什麼這樣做會變好玩」。

> 前提（不動）：**幣＝拆包力**（`grant()` 每一單位 P 同時進錢包又推進包），收入跟第幾包無關。
> 這跟 CH「金幣∝區數」不同，所以 v3 不照抄 CH 的金幣曲線，只借它的**牆**與**有限輪迴**。

## 一、為什麼 1.0 現在不好玩（兩個根因）

| 根因 | 現況 | 玩家感受 |
|---|---|---|
| 沒有牆 | 王包血量 `1.25×(30P+180D)` 跟自己掛鉤 | 王永遠是「30 秒左右一場」，你變強它也變強；沒有「過不去、得回去養」的時刻，所以編隊／訓練／輪迴都沒有被需要 |
| 倍率無上限 | 印記∝√生涯幣、兩條無頂倍率互餵 | ×76,000；所有內容秒殺；「變強」失去意義 |

**好玩的放置遊戲只有一種節奏：撞牆 → 想辦法（換隊、養、輪迴）→ 突破 → 下一道牆。**
沒有牆就沒有「想辦法」，玩家只剩點點點。v3 全部圍繞「把牆放回去，然後給玩家四種想辦法的工具」。

## 二、牆：小王與大王的血量改成關卡函數

### 為什麼會變好玩
血量跟玩家無關，玩家的強度才是**自己建的**。撞牆時玩家知道「我差 30%」，而且知道差距能靠什麼補——這是 CH 十年沒變的核心。
每 10 包一隻小王，是讓牆**細**：不是每站一次、而是每兩三分鐘一次小檢查，節奏才有起伏。

### 規則
- **小王**：每站第 10、20、30… 包（`gate = index % 10 === 0`）出現，擋住下一包。血量 `G × requirement(index)`，**30 秒**計時。
  打贏繼續；打輸 **30 秒冷卻**後可再挑（冷卻中照常賺錢、不能推包）。
- **大王**（站王）：血量 `K × requirement(門檻包+1) × cfg.mul`，不再讀 P／D；30 秒；打輸 3 分鐘冷卻（現行）。
- **每 5 隻小王一個「area」**：第 5 隻的血量倍率 ×1.5（Sakura 的 2→6 節奏縮成 1／1／1／1／1.5），讓站內也有「這隻比較難」的起伏。
- **自動挑戰開關**（`settings.autoChallenge`，預設開）：小王一出現就自動開打、輸了冷卻完自動再打；關掉＝手動點才打。這是 CH 的 progression toggle——玩家想「先存錢買一輪再打」時要有地方停。
- 大王的**通關章**：本輪打贏過的站，下一輪門檻包數減半（roadmap §7 原案，現在真的用得到）。

### 數字（起點，模擬器定）
- `G = 2`、`K = 4`。含意：小王要求「**15 秒內拆完當前包**」的拆包力（含點擊與技能），大王要求「7.5 秒拆完門檻包」。
  純放置約只有 60%，連點＋技能 110～140%（v2 已量過的三種打法比例）——**放置過不了王，連點＋技能才過得了**，這就是「想辦法」。
- 驗收：第一天（20 分鐘 × 3 段 ＋ 睡眠離線）撞到的第一道**大王**牆落在第 3～4 站；第一次輪迴在第 2 天。

## 三、編隊進 1.0（出身算層）

### 為什麼會變好玩
現在 P＝**全部擁有的角色**加總——收集越多越強，沒有選擇。改成只算隊伍 20 張，「帶誰」變成一個決定；
加上第五節的本輪當家，**每一輪的最佳 20 張都不一樣**，收集才有「用」而不只是「有」。
戰力上限綁在格子上，以後出新卡不會膨脹（同末世）。

### 規則
- `s.roster`：≤20 個 id，前綴上限 2／6／12／20，**用出身（原生稀有度）算層**，升階不改所屬層（使用者 2026-09-12 定案 (a)）。
- `rates().P` 只加總 roster 內的角色；不在隊的 32 張**不產錢**，但可以派遣（§六）。
- 技能槽維持 3（第四槽仍是印記商店商品）；技能槽裡的卡**必須在隊伍裡**。
- 遷移（大掃除）：自動填一隊——按 `individual()` 由高到低塞、撞上限就跳過。
- UI：把 `holo-5.0` 的 `team20` 編隊畫面（拖曳、上限列、挑選器）搬進 1.0，卡面用 1.0 現有卡面。⚠ 這件事**提前把 team20 搬進 main**，跟「等末世能玩才併」那條要分開看——只搬編隊，不搬精裝卡與抽卡演出。

## 四、印記：事件計數、有頂、單一倍率

### 為什麼會變好玩
輪迴的樂趣是「這一輪我做到哪」——獎勵必須是**進度**的函數，玩家才會為了多一枚印記多推一站。
產出是幣的函數時，最佳策略是「掛著等」，沒有決策。有頂則讓「全滿」變成一個可以達成的目標，而不是無限的數字。

### 規則
| 項目 | v3 |
|---|---|
| 每輪印記 | 本輪打贏的大王每隻 **1**（最多 7）＋本輪累計拆滿 100／300 包各 **1**＋本輪打贏滅世珍獸再 **+3** → 每輪上限 **12** |
| `markMul` | **拿掉**（係數 0；欄位保留） |
| 收益祝福 | 每級 +10%，**上限 Lv.20（×3.0）**，第 L 級收 L 枚（全滿 210） |
| 招募券 | **拿掉** |
| 粉塵兌換 | 遞增價不變（已封頂） |
| 商店 10 項 | 不變（一次性） |
| 生涯總需求 | 225 枚 ≈ 19 輪全滿 |
| 王計時 | 商店已有「王包 +10 秒」；小王共用同一項（30→40） |
| 輪迴條件 | 生涯幣門檻改成「本輪至少打贏 1 隻大王」 |
| 大王可重打 | `runWins`（本輪）與 `bossWins`（永久解鎖）分開；輪迴清 `runWins` |

## 五、本輪當家（CH Gilded）

### 為什麼會變好玩
每次輪迴隨機 2 張卡 ×1.5，**這一輪的最佳隊伍就跟上一輪不一樣**——編隊從「一次算好」變成「每輪重想」。
隨機性給的是「這輪抽到珍母當家！」的小驚喜，成本是零（不影響上限：×1.5 只在本輪）。

### 規則
- 輪迴時從**已擁有**的角色隨機抽 2 張存 `s.champions`；`individual()` ×1.5、技能 CD −20%（沿用場景親和的形狀）。
- 第一次進遊戲（沒輪迴過）也抽 2 張，讓新手第一輪就有。
- 卡面與編隊網格顯示「本輪當家」小旗（跟場景親和的「當家」旗同一元件、不同顏色）。

## 六、派遣（CH Mercenaries）

### 為什麼會變好玩
編隊 20 之後有 32 張卡沒事做——派遣讓「收藏」有一個**不影響戰力**的出口：把不在隊的卡送出去幾小時，回來帶粉塵。
「下線前派 3 張、上線先收」是放置遊戲最好的回訪理由，比每日任務自然。

### 規則
- 3 個派遣格（`s.dispatch = [{id, startedAt, until}]`），只能派**不在 roster 的卡**，派出中不能編入隊伍。
- 時長固定 **4 小時**；回收給**該角色專屬粉塵 1 顆**（傳說／神話 0.5 顆，累計）＋ 萬用粉塵 1 顆。
  粉塵是 1.0 的長線貨幣、不乘任何倍率，所以派遣**不會膨脹**。
- 每日上限：3 格 × 最多 3 輪＝每天最多 9 顆萬用粉塵（每日一包 1 顆的九倍，但要真的回來收三次）。
- 輪迴**不清**派遣（它跟戰力無關）。

## 七、精良技能的新型別：重整（Reload）／充能（Energize）

### 為什麼會變好玩
CH 最有名的組合技是 Reload（重置 CD）與 Energize（下一個技能 ×2）：它們自己不打傷害，卻讓**順序**變成解題。
這正是四階分工裡「精良＝資源與穩定度」的範本——精良卡不是弱版傷害卡，是**讓其他卡更強的卡**，永遠不過期。

### 規則
- 新 `kind`：`reload`（其他槽 CD 立即歸零；CD 180s）、`energize`（下一個發動的技能效果量 ×2；CD 150s）。
- 先套在兩張精良卡上（不動它們的被動 base）：**seal 快樂拍拍 → 充能**、**chaichai 柴柴打滾 → 重整**。⚠ 這是改既有卡的技能，要使用者點頭。
- 連鎖窗照算（reload／energize 本身也算一次發動）。

## 八、寶箱包

### 為什麼會變好玩
CH 的寶箱怪是「隨機的小確幸」（×12.5 金）——放置遊戲需要**不可預期的正回饋**，否則曲線太平。
1.0 已有夜市禮包（限時、要點），寶箱包是不用操作的那種：拆到就是賺到。

### 規則
- 每包 **3%** 機率是寶箱包（外觀：金色包裝）；拆完額外 `requirement × 8` 幣（不進包進度）。
- 夥伴訓練里程碑 **Lv.150** 新增「寶箱率 +1%」（每隊員最多 +1%，隊伍 20 人最多 +20% → 23%）。
- 離線結算不出寶箱。

## 九、點擊附加隊伍收益

現行 `D = trait × (M×1.15^Lv + .05×M×P)` **已經有** 5% 的隊伍收益附加。
v3 把它做成看得見的成長：印記商店新增「點擊附加 +5%」（3 枚、可買 2 次，上限 15%）。
理由：後期點擊不能歸零，否則「連點＋技能才過得了王」（§二）不成立。
