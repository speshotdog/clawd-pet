## 問題一：一半的畫面是完全空的（可量）

我把成圖切成縱向四等分，量邊緣密度（>24 亮度階/px 的像素占比）：

| 縱向四等分 | 邊緣密度 |
|---|---:|
| 第 1 段 y=0–404 | **0.000%** |
| 第 2 段 y=404–809 | 2.532% |
| 第 3 段 y=809–1214 | 3.956% |
| 第 4 段 y=1214–1619 | **0.000%** |

**上四分之一與下四分之一裡什麼都沒有，一個像素的邊緣都沒有。**
這一段地圖要放 **4 個節點**，照這張圖，其中兩個會坐在純色塊上。

⚠ 我上一輪只寫了「上下各留 8～12% 的過渡帶」與「中央垂直帶保持單純」，
你把它執行成「上下各 25% 全空」。**過渡帶是 10%，不是 25%；
中央帶是寬度的 30%，不是整個下半部。** 這一條是我沒寫下限造成的，這一輪補上。

### 這一輪的門檻（上下限成對）

把畫面 **y=[10%, 90%]**（扣掉上下過渡帶）切成**四等分**，每一等分內：

- **左 35% 的邊緣密度 ≥ 0.8%**，**右 35% 的邊緣密度 ≥ 0.8%**（下限，防止空白）
- **中央 30% 的邊緣密度 ≤ 1.2%**（上限，維持節點可讀）
- 上下過渡帶（各 10%）維持乾淨，邊緣密度 0～0.3%

量法用你上一輪那套（Y=0.2126R+0.7152G+0.0722B，NumPy gradient，門檻 24），
把每一格的數字寫進回報。

## 問題二：這不像廢墟，像後院在傍晚（可數）

現況：草地是均勻乾淨的橄欖綠，除了**樹冠焦黑、柵欄缺兩片、布撕一角**之外沒有任何破壞。
1.0 的地面是「亮綠 ＋ 小花 ＋ 草叢 ＋ 木棧板」，新版只是**把顏色調暗**——
那是調暗，不是毀掉。使用者要的是「滅世珍獸把這裡毀了」。

### 這一輪要加的（數量有下限，方便驗）

**散落的殘骸 ≥ 6 件**，分布在**至少 3 個**縱向四等分裡，而且**全部避開中央 30% 帶**。
建議的母題（都要是 1.0 那個世界的東西，不要憑空放瓦礫）：

- 翻倒的野餐籃、掉出來的食物
- 破掉的盤子／杯子碎片
- 1.0 那個**紅白零食包裝袋**（`gacha-pack.png` 那種）被撕開、散落
- 狗玩具（球、恐龍）半埋在土裡
- 斷掉的柵欄板散在地上
- 枯黃倒伏的草塊、裂開的土

**地面本身也要被破壞**：不要一整片均勻綠。要有枯黃斑塊、裂縫、翻起的土。
⚠ 但**中央 30% 帶的破壞要用大面積、低對比的方式**（例如整片枯黃色塊），
不要在中央畫細碎的裂紋——那會讓節點讀不清。

### 天空也要保留識別線索

1.0 的天空是**三層水平色帶**（亮藍／淺藍／更淺的地平帶，見 `ref-1.0-backyard.png`）。
現況換成單一深藍，那層結構不見了。

**保留那三層水平色帶的結構，把它壓暗＋染上災後的色（偏灰／偏土）**，
再加遠處的煙或塵。**「同一片天」也是識別線索之一。**
