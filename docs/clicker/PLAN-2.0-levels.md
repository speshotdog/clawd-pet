# 2.0 末世地圖：關卡規劃（第一步，只做關卡）

依使用者要求的順序：**先做關卡 → 之後再提機制 → 一步一步做。**
所以這份**只寫關卡骨架**：有幾段、每關是什麼地方、王擺哪、王的機制對應哪個素材。
**數值、技能戰力、模擬器都不在這份裡面。**

前置裁決（見 `DESIGN-team-and-map.md` 第七節）：

- 一般關 **純放置／點擊，不加機制**；機制**只放在王關**
- **打不死就不能進下一關**；一般關失敗只損失時間；**王關失敗 3 分鐘冷卻**
- 地圖**線性**，只能用精裝卡

---

## 一、地圖的主題 ★已定案：甲

2.0 接在 1.0 第七站「滅世都市」打完王之後。1.0 走的是**零食與家居**
（後院草地→廚房流理台→便利商店貨架→零食工廠→夜市攤→深夜冰箱→滅世都市）。

| 方案 | 地景是什麼 | 好處 | 壞處 |
|---|---|---|---|
| **甲（已採用）走過 1.0 的廢墟** | 滅世珍獸把 1.0 那些地方全毀了。2.0 一路走過**同樣七站的末世版本**，最後回到城市，看見真身 | 玩家一眼認得出「這是我玩了一整輪的後院」，毀滅感是免費的；**最後一關回到城市，跟真・滅世珍獸的『城市就是牠』完全接得起來** | 地景要重畫，不能直接套 1.0 的圖（1.0 的圖是明亮拼貼風） |
| **乙 全新的末世地景** | 公路、地下道、電塔、輻射帶…跟 1.0 無關的新地方 | 自由度最高，不受 1.0 美術限制 | **少了「這是我家」的情緒**；跟真身的城市呼應要另外造 |
| **丙 混合** | 前半是廢墟版舊場景，後半走進沒去過的地方，最後回城市 | 兩邊都有 | 段落感容易鬆掉，要多花力氣讓中段不像換了一款遊戲 |

⚠ 甲不等於「重用 1.0 的 PNG」。1.0 的 `clicker-scene1-*` 那批是明亮拼貼風，
直接壓暗會變成 astra 清單裡的「把 1.0 CSS 全域改暗」——那條是明確不做的。
甲的意思是**構圖與地標認得出來，材質與色調全部新做**。

## 二、分段：五段，每段一個王

四個 BOSS 素材 ＋ 真・滅世珍獸 = **五個王**，所以地圖切成五段。

```
第一段 → 王①  →  第二段 → 王②  →  第三段 → 王③  →  第四段 → 王④  →  第五段 → 真・滅世珍獸
```

每段建議 **3～4 個一般關 ＋ 1 個王關**，全圖約 **19～24 關**。

- **下限 3**：少於 3 關，玩家等於一路都在打王，機制會從「特別」變成「常態」，
  跟使用者說的「小怪都套用很擾人」是同一個問題的另一面。
- **上限 4**：多於 4 關，純放置的一般關會開始重複。

**已定案：五段、每段 3～4 關。**（原本的選項留在下面存檔）

★ 原本的問法：**五段是不是你要的長度？** 想更長就加一般關的數量（3→4），
想更短就砍到四段（等於放棄一個 BOSS 素材）。**不建議加第六個王**，因為只有四個素材。

## 二之二、五段是哪五個地方（甲案展開）★這是這份新增的核心

1.0 有七站，2.0 有五段——**兩處合併，各有理由**，而且每一個合併都同時
給那一段的王一個「為什麼是這隻、為什麼長這樣」的敘事理由。

| 段 | 地景（1.0 的哪一站）| 王 | 素材 | 機制 | 為什麼配在一起 |
|---|---|---|---|---|---|
| **一** | **後院草地・廢墟** | 王① | `01.gif` 灰狼犬 | **召喚小怪** | 野狗群占據了後院。**牠不出來，派狗群上**——素材只有 180px 正好讓牠待在遠處 |
| **二** | **補給線**（便利商店貨架 ＋ 零食工廠）| 王② | `ej93j4.gif` 貼紙羊 | **護盾層** | **那圈粗白邊＝一層層的包裝膜**。在貨架與工廠這一段，「被包起來的東西」不需要解釋 |
| **三** | **夜市攤・廢墟** | 王③ | `image.gif` 扛槌兔 | **節奏／節拍** | 夜市本來就有敲擊聲。**9 格揮槌循環＝節拍來源**，槌落地那一格就是拍點 |
| **四** | **冷藏庫深處**（廚房流理台 ＋ 深夜冰箱）| 王④ | `rise.png` 雞頭合成怪 | **按順序打部位** | **牠是凍住的**——這給了「只有一格靜態」一個敘事理由，不是素材偷懶。動的是霧與指示標記 |
| **五** | **滅世都市** | 王⑤ | 真・滅世珍獸（素材未定）| **前四種輪播** | 回到 1.0 最後一站。城市輪廓就是伏臥巨獸的背脊 |

**合併的理由**（不是為了湊數）：

- **二**：便利商店貨架與零食工廠在 1.0 是「東西從哪來」的同一條線，末世版合成「補給線」很自然。
- **四**：廚房流理台與深夜冰箱本來就同一個廚房，末世版合成「冷藏庫深處」，
  而且**「凍住」正好解釋 `rise.png` 為什麼不動**。

⚠ 這五段的順序**跟 1.0 的順序不同**（1.0 是 廚房→貨架→工廠→夜市→冰箱→城市）。
2.0 把廚房挪到第四段，是為了讓「凍住」出現在後段、離城市近。
**如果你要保持 1.0 的原順序，第四段的王就要換一個機制**——請現在說。

### 每段最後一關是「預告關」

進王關之前的最後一個一般關，地景開始出現下一個王的痕跡，**但不加機制**：

| 段 | 預告的痕跡 |
|---|---|
| 一 | 草地上一片片被踩平的路徑、遠處有東西在看 |
| 二 | 貨架間纏著撕不斷的包裝膜 |
| 三 | 地面固定間隔的槌痕（**痕跡的間隔就是之後的拍子**）|
| 四 | 結霜的地板上有一排腳印，但形狀對不上任何一種動物 |
| 五 | 街道開始出現不該有的弧度 |

第三段那條特別重要：**槌痕的間隔先讓玩家看見節奏，王關才不會是突然的反應力測驗。**

## 三、王的機制怎麼配素材 ★這是這份最重要的一段

原則：**用素材本來的缺點當設計，不要跟它對打。**
四個素材各有一個麻煩（太小、白邊粗、要去背、只有一格），
下面每一個都是把那個麻煩變成機制的理由。

| 王 | 素材 | 機制 | 為什麼是這個機制 |
|---|---|---|---|
| **王①** | `01.gif` 灰狼犬（180×180，最小，放大會糊）| **召喚小怪：先清掉狗群才打得到牠** | 牠小、放遠景才好看——那就讓牠**待在遠處不出來**，前面一直有小怪擋著。素材小反而合理了 |
| **王②** | `ej93j4.gif` 貼紙羊（1000×1000，白邊很粗）| **護盾層：一層一層打掉外殼**（1.0 的 `enemy.shell`）| **那圈粗白邊就是牠的殼。** 不用去背、不用消白邊，反而把它畫成一層一層剝掉的東西 |
| **王③** | `image.gif` 扛大槌的兔（9 格，站在裂地上）| **節奏／節拍：在槌落地的拍子上點** | 9 格動畫本來就是一個揮槌循環，**動畫的週期直接就是節拍**。素材自己提供節奏來源 |
| **王④** | `rise.png` 雞頭合成怪（靜態，只有一格）| **順序：按指定順序打牠身上的部位** | **牠不會動**——這是唯一一個「靜止不動反而正確」的機制。動的是背景霧與指示標記 |
| **王⑤** | 真・滅世珍獸（素材未定）| **前四種輪流出現**（最終考試）| 玩家四段各學一種，最後一關全部要用；這也讓最後一關**不需要第五種新機制** |

⚠ 三件要記住的事：

1. **`image.gif` 與 `rise.png` 是白底不是透明，要去背。**
   去背驗收用**輪廓／覆蓋率**（主體遮罩保留 98～100%、輪廓 IoU .97～1.00、
   殘留白區占原背景 0～0.5%），**不要用逐像素差**——GIF 的抖色會讓像素級比對到處是假訊號。
   GIF 要**逐幀驗**，不能只驗第一幀。
2. **`ej93j4.gif` 那圈白邊不要去掉**，它是王②的機制本體。
3. 四個素材尺寸差 5.5 倍，**不要強迫牠們同一個大小或同一個動作頻率**
   （astra：靠全體呼吸縮放遮掩靜態素材＝把破綻藏起來，角色也跟著消失）。

**已定案：四組配對全部採用。**（原本的問法留在下面存檔）

★ 原本的問法：**這四組配對可以嗎？** 特別是王④「按順序打部位」——
如果你比較想要別的（例如「限時內打完」或「反擊要閃」），現在說最便宜。

## 四、一般關卡是什麼

**純放置／點擊，不加機制**（使用者定案）。所以一般關的差別只有三樣：

| 變什麼 | 說明 |
|---|---|
| **地景** | 走到哪一段就是哪個地方（第一節的甲／乙／丙決定）|
| **難度** | 需要多少產出才過關 |
| **王前的最後一關** | 建議放一個「預告關」：地景開始出現下一個王的痕跡（狗毛／羊毛／槌痕／羽毛），但**不加機制** |

「預告關」是唯一的例外，而且它加的是**視覺**不是機制——
玩家在進王關之前應該已經知道「前面有東西」，這樣王的登場才有份量。

⚠ 一般關不要放：掉落預覽、關卡星等、體力、每日任務、加速鈕。
（astra 的「不該做」清單，已採用。3 分鐘王關冷卻是這條線**唯一**的等待循環。）

## 五、進度規則

```
一般關失敗  → 只損失時間，立刻可重試
一般關通過  → 解鎖下一關
王關失敗    → 3 分鐘冷卻，冷卻中王關節點顯示剩餘時間
王關通過    → 解鎖下一段
打不死      → 不能進下一關（線性硬牆，這是唯一的代價）
```

⚠ **這個設計把「編隊有沒有意義」全部押在難度曲線上。**
硬撞不扣東西，但硬撞也過不去——唯一的出路是改隊或變強。
所以之後寫模擬器時要量的不只是戰力上限，還有：
**每一關的最低通關隊伍組成，不能整條地圖都是同一組。**
如果同一套隊伍能輾完 19～24 關，編隊系統就是假的，跟有沒有代價無關。

⚠ 冷卻中的王關節點要**顯示剩餘時間**，不能只是變灰。
（astra 的驗收：任務測試中「不能返回或沒有下一步說明」的死路數量 **0**。）
