## 任務 A：本草珍目的羊往上移

### 現況（我量的）

| 卡 | 主體上緣 | 主體下緣 | 垂直中心 | 高度 |
|---|---:|---:|---:|---:|
| **本草珍目** | 37.0% | **75.7%** | **56.4%** | 38.8% |
| 滅世珍獸（參考）| 24.4% | 82.0% | 53.2% | 57.7% |
| 沙堡領主（參考）| 25.1% | 74.9% | 50.0% | 49.9% |

名字框上緣在 **80.4%**，所以現在羊的下緣離名字框只剩 **4.7%**，整隻偏低、偏擠。

### 要改成

**只移動位置，不改大小。**

| 判準 | 下限 | 上限 |
|---|---:|---:|
| 主體垂直中心（佔卡高）| 48% | 53% |
| 主體下緣到名字框上緣的間距 | 7% | 14% |
| 主體高度（不准趁機縮小或放大）| 37.8% | 39.8% |

上限存在的理由：往上太多會頂到卡片上緣、也會把上排的植物貼紙擠掉。
高度那條是上下限夾住現值 ±1%——**這一輪不是重新構圖，只是把羊抬高一點**。

### 要小心的兩件事

1. 背景在羊的舊位置是**補畫過的**。羊移走之後那塊會露出來，
   要確認補畫的痕跡在新構圖下看起來仍然自然（沒有殘影、沒有一塊突兀的乾淨區域）。
2. 如果背景裡有跟著羊的**接觸陰影**，陰影要一起移動；留在原位就會看到「影子掉在地上」。

### 驗收

- 上表三條門檻的實測值
- 背景在主體剪影範圍內 alpha == 0 的像素數 **== 0**
- **改前／改後並排圖**（同尺寸、同一張卡）。並排圖看起來沒差就是沒做到。
- 三種尺寸（102 / 190 / 262px）截圖，確認仍然滿版、名字沒被蓋住

## 任務 B：卡包的待機表現

使用者要的是「**像遊戲道具**」——現在它太靜態，站在那裡不動，看起來像一張圖不像一件可以拿起來的東西。
三個子項，**三項是一組**，不要只做其中一項就交。

### B-1. 滑上去會稍微放大（被選取感）

- hover 時卡包整體放大，**放大幅度 1.03×～1.08×**
  （下限＝要感覺得到；上限＝再大就變成彈出視窗了）
- 進場 120～200ms、離開 160～260ms，`ease-out` 系
- **要跟現有的拖曳旋轉相容**：hover 放大不得干擾拖曳中的傾斜角度，
  拖曳中不要同時再放大一次
- 滑鼠已經在卡包上時，**放大狀態不得跟呼吸動畫打架**（見 B-2）

### B-2. 平常會呼吸懸浮

- **上下浮動**：振幅 **4px～10px**，週期 **2.8s～4.5s**
- **呼吸縮放**：**1.00×～1.025×** 之間起伏，跟浮動**不同週期**
  （同週期會變成整齊的脈動，那不像有生命的東西）
- 兩者都要 `ease-in-out` 系，不能是線性
- 這是**待機**表現：抽卡演出開始（推近之後）就要停下來，
  不要讓卡包在等待點擊時還在飄——那會讓「點我」的意圖變模糊

### B-3. 周遭循環的光暈特效

- 光暈在卡包**外圍**，不是蓋在卡面上（卡面已經有箔面反光，兩者不要打架）
- **循環**：完整週期 **3s～6s**，無縫接回（不准有跳格）
- 亮度：光暈最亮時，卡包外圍 12px 環狀區域的平均亮度增量
  **≥8 灰階、≤28 灰階**（下限＝看得見；上限＝別把黑底洗白）
- 顏色取自卡包自己的配色，**不是固定白光**
- ⚠ **不預告品質**：待機表現與光暈**不得因為裡面抽到什麼而不同**。
  這是已定案的契約——開包前不同稀有度必須逐像素零差。

### B-4 效能與無障礙

- 這三項**全部用 CSS `transform`／`opacity`／`filter` 做，不准開 rAF 迴圈**：`idleRaf == 0`
- `prefers-reduced-motion` 時：停掉浮動與呼吸，光暈改成靜態，hover 放大保留（那是回饋不是裝飾）

### 驗收

| 判準 | 怎麼量 |
|---|---|
| hover 放大 1.03–1.08× | 逐幀取 `getBoundingClientRect`，比 hover 前後的寬度比 |
| 浮動振幅 4–10px、週期 2.8–4.5s | 決定性取樣整個週期的 y 位移，取極值與過零間隔 |
| 呼吸與浮動週期不同 | 兩個週期的比值不得落在 0.95–1.05 |
| 光暈週期 3–6s 且無縫 | 取 t=0 與 t=週期 的畫面，逐像素差 ≤2 灰階 |
| 光暈亮度增量 8–28 灰階 | 外圍 12px 環狀區域，最亮幀 vs 最暗幀 |
| 不預告品質 | 五種稀有度各開一次，開包前同一時刻截圖，**逐像素零差** |
| 拖曳仍不觸發開包 | 拖曳 20 次觸發 0 次；點擊 20 次觸發 20 次（沿用上一輪的測法）|
| 待機動畫在演出開始後停止 | 推近完成後 500ms 取兩幀，卡包位移 == 0 |
| `idleRaf == 0` | 沿用既有量法 |

**並排／逐幀證據**：交一段「待機 3 秒」的逐幀取樣圖（至少 6 格），
以及 hover 前／hover 後的並排圖。**看不出在動就是沒做到。**
