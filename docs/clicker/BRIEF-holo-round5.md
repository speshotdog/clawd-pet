## 二、寶石重做（第四輪這項是失敗的）

第四輪把寶石移進銘牌左側、做了三種款式（切面／軌道／棱鏡）、加了 glow 與 hover 反應——
**規格有做到，但視覺失敗**：實際渲染出來在深色銘牌上暗到跟背景融在一起，
只剩一團模糊的深色圓塊；五階並排區更被縮到 8px，那個尺寸怎麼設計都看不見。

使用者的判斷是「**舊版卡面的寶石比較好看**」。這是很強的訊號：

1. **先去看舊版寶石到底做了什麼**——`src/gacha-card.css` 的 `.face-gem`（第 105 行）、
   `.skin-af .face-gem`（236）、`.r-common`（240）、`.r-mythic` 的 conic-gradient（393）。
   **實際讀那段 CSS**，弄懂它為什麼比新版好看（尺寸？位置？對比？色彩？描邊？背景襯底？）。
   把結論寫進 README——這是本輪最重要的一段分析，不要跳過。
2. **回到舊版那個方向重做**，而不是繼續改第四輪那三款。可以在舊版基礎上加材質與光暈，
   但**不要犧牲它原本好看的原因**（很可能是「夠大、對比夠、有實心亮面」）。
3. **使用者問「有沒有其他開源的設計可以用」——這題要正面回答。**
   實際去找開源的寶石／稀有度徽記設計（CSS/SVG 皆可），
   ⚠ **必須實際讀 LICENSE 原文**再判斷能不能用；GPL 的只能學不能抄
   （見 `DESIGN-holo-cards.md` 第 8.2 節既有結論）。
   找不到可用的就誠實說找不到、只能自製，**不要為了交差硬掰一個「參考來源」**。
4. 五階並排區的寶石**不准縮到看不見**。如果版位放不下，改版位，不要縮元素。

## 三、字體：放大、懸浮、傳說以上要誇張

1. **字要大一點**。目前 `.face-name` 是 `clamp(12px,1.45vw,21px)`，
   五階並排區還被壓到 12px。整體往上調，並確保縮圖以外的地方都讀得清楚。
   放大後**第四輪那三組間距驗證（名字↔寶石／銘牌邊／卡框）仍然要過**——
   要靠改版面撐開，不是把字縮回去。
2. **字也要懸浮**。第三輪給了文字 Z 深度，但幅度顯然不夠明顯。
   加大名字的 Z 位移與視差，讓它明確地浮在卡面之上（可讀性仍優先）。
3. **傳說以上要有「遊戲風格的誇張感」或「像素風」——使用者要你提出幾種設計。**
   做 **3～4 種**方向進展示頁讓他切換挑，例如：
   - 遊戲 UI 風：厚描邊 ＋ 內陰影 ＋ 金屬漸層 ＋ 外發光
   - 像素風：點陣字體（像素中文字體要找開放授權的，找不到就只做英文稀有度標，
     中文名另一套處理，並在 README 說明）
   - 立體浮雕／燙金壓印
   - 誇張斜體 ＋ 拉伸 ＋ 分層描邊
   ⚠ 只有 **legendary 與 mythic** 用誇張版；common～epic 維持乾淨可讀，
   這個對比本身就是稀有度的一部分。
   ⚠ 字體授權沿用第四輪：只用明確開放授權（SIL OFL 等），要讀原文、檢查 Reserved Font Name。

## 四、必修：使用者打不開圖（本輪最高優先）

> 「**HTML我會看不到圖 只看的到框**」

原因：`demo.html` 用相對路徑引用 `_art/holo-test/*.png` 與 `../../src/card-*.png`，
使用者拿到的只有那一個 HTML 檔，圖沒有跟著走，所以只看得到框。

要交付**一個真正自包含的單檔** `_art/holo-test/demo-standalone.html`：

- **所有圖片內嵌成 data URI**，不依賴任何外部檔案，
  丟到任何地方、任何機器打開都要看得到圖。
- ⚠ **有大小上限：整個檔案要壓在 15 MB 以內**（要拿去發佈成網頁）。
  目前相關 PNG 原始檔合計約 28 MB，base64 後約 38 MB，**直接內嵌會爆掉**。
  壓縮策略自己決定，建議方向：
  - 背景層不需要 alpha → 轉 JPEG 或 WebP（有損）
  - 主體層需要 alpha → WebP with alpha 或量化後的 PNG-8
  - 貼圖（fiber／glitter／engraving）可降解析度或改程式即時產生
  - 展示用不需要 600×840 全解析度的每一張，可依實際顯示尺寸重採樣
- 壓完要**自己開來看**，確認畫質沒有爛到看不出箔面與景深的差異——
  這個檔是拿給使用者做視覺驗收的，壓過頭就失去意義。
- 原本的 `demo.html`（相對路徑版）保留，開發時用那個。
- 在 README 寫明兩個檔的差別與 standalone 的實際大小。
