## 一、音量與淡入淡出（`clicker-music.js`、頂列 UI）

### 預設音量與拉條
- 場景曲外層 gain 預設從 .55 → **.24**（約 -56%）；技能曲 .7 → **.32**。兩者都再乘上使用者音量 `settings.musicVolume`（0–1，預設 .6）。
- 音效（GachaAudio scope 的點擊／升級／切入三段音）乘 `settings.sfxVolume`（0–1，預設 .8）。
- 頂列「音效開」「♪ BGM」兩顆按鈕改成一顆「♪」按鈕，點開一張小紙板浮層（`clicker-ui-paper.png`，160×110，錨在按鈕下方）：兩條拉條「音樂」「音效」（`<input type=range>` 皮成紙膠帶軌道＋圓貼紙滑塊，滑塊用 `clicker-ui-sticker-badge.png` 40px），各自左側一個靜音小開關。拉動即時生效、放開才存檔。浮層點外面關閉；Esc 關閉。
- 拉條變更時音樂用 200ms `setTargetAtTime` 平滑到新值，不要跳。

### 淡入淡出（重點：不要突兀）
現況是 300ms 線性 ramp，兩首直接對撞。改成遊戲常用的「先讓路、再進來、等比曲線」：

**技能發動（t=0 是切入開始）**
1. 場景曲 **先 ducking**：0→400ms 從當前值降到 15%，用 `setTargetAtTime(target, now, 0.12)`（指數逼近，時間常數 120ms），不是線性。
2. 技能曲 **等一拍再進**：延遲 260ms（切入面板撞入那一格，讓音樂進場跟畫面撞擊同步）開始，`skillGain` 從 0 用 **等功率曲線** 升到目標，長度 700ms：`setValueCurveAtTime(curve, now, .7)`，curve 為 `sin(i/N * π/2)` 的取樣 64 點乘目標值。
3. 技能曲前 700ms 同時開一個低通：`BiquadFilter lowpass` 從 900Hz 掃到 14kHz（`exponentialRampToValueAtTime`），像從遠處衝過來。
4. 技能曲從 step 0 起播（不變）。

**效果結束**
1. 技能曲用等功率曲線 **1400ms** 退到 0（`cos(i/N * π/2)`），同時低通從 14kHz 掃回 1.2kHz（像退場）。
2. 場景曲 **晚 300ms** 開始用等功率曲線 1400ms 回到目標；兩條曲線的重疊區用等功率保證總能量不凹陷。
3. 場景曲不停、不重頭（維持現在）。

**連續技能**：仍在技能曲時再發動：不重啟、不重淡，只延長；已進入退場淡出中再發動：取消退場 curve（`cancelAndHoldAtTime`），用 400ms 等功率回到目標。

**開窗第一次播放**：場景曲 0 → 目標 用 **1200ms** 等功率淡入，不要一開就滿。

**隱藏／靜音／關 BGM**：300ms 等功率淡出後才 suspend。

所有淡化都用 AudioParam 排程，不用 setInterval 手動改 gain。

## 二、場景可讀性（`clicker-scene.js`、`clicker.css`）

### 樹接上樹幹
現況三團樹冠浮在樹幹旁邊、沒接到枝。改法：以樹幹圖實際的兩個枝頭座標為錨（量 `clicker-scene1-tree-trunk.png` 的分枝端點），樹冠三團分別蓋在「左枝頭」「右枝頭」「主幹頂」，每團中心在枝端向上 8–12px，團與團**互相重疊至少 20%**，中間那團最大（高 120）、左右兩團 96／88，z 序：中 > 右 > 左。樹幹在樹冠**後面**露出下半段即可。搖擺樞軸改在各團與枝端的接點。若素材比例真的接不起來，把整棵樹改成「樹幹＋單一大樹冠（三團合成一個 DOM，整體一個搖擺）」也可以，但要說明。

### 背景太花、珍母不清楚
三招同時做：
1. **場景整體退一步**：場景根 `filter: saturate(.78) contrast(.92) brightness(1.04)`；遠景層再多一層 `opacity:.85`；近景草花維持原色但 `saturate(.85)`。目的是讓場景像水彩底、角色像貼上去的貼紙。
2. **珍母底下一個舞台光**：在珍母正後方放一個 300×220 的奶白徑向漸層（`radial-gradient(ellipse, #FFF6E6cc 0%, #FFF6E600 70%)`），z 在場景之上、珍母之下，靜態不動；再給珍母 SVG 一圈 3px 奶白描邊光暈（`filter: drop-shadow(0 0 0 #FFF6E6) drop-shadow(...)` 四方向各 2px，或用 `-webkit-text-stroke` 不適用 SVG，就用四個 drop-shadow）。
3. **減少高頻**：草叢從 6 株減到 4 株、花從 4 朵減到 3 朵，避開珍母正下方 ±120px；道具只留郵筒；雲只留兩朵且不進入珍母頭頂區域（y < 60 才允許）。

### 珍母置中
- `#hero-position` 與 `#tap` 移到舞台水平正中：left = (608−240)/2 = **184px**（回到第一版位置），垂直不變。
- 包裝維持右下（x392 不動或微調到 x410 讓它離珍母遠一點），技能槽三顆維持左下。
- 切入的 `--focus-x` 珍母版改成 **320px**（舞台中心）；`clicker-cutin.js` 只改這一個數字（在 `play()` 的 `root.style.setProperty('--focus-x', ...)`），其餘不動。
- 寄生標籤、接觸影、舞台光跟著珍母移。

## 三、浮字（`clicker-stage.js` 的 `float()`、CSS）

現況：20px、深色字、無底，掉在草地上看不見。改成「紙標籤數字」：
- 字級 **26px**（連點 28px、重擊 34px），字重照粉圓＋`-webkit-text-stroke: 1.2px #30251F`，填色**奶白 `#FFF6E6`**，再加 `text-shadow: 0 2px 0 #30251F` 硬陰影一層。
- 金幣圖 22px。
- 上升距離 36 → **56px**，時長 480 → **720ms**，最後 200ms 淡出；起始 60ms 的 `scale(.6→1.15→1)` 彈出保留。
- 連點第 3 下起顏色改金 `#E9B94E`，重擊 `#EF8E8E`，都保留描邊與硬陰影。
- 同時在場上限維持 12，合併規則不變。
