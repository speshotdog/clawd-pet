## 一、把美術接進去

### 地景
- **第一段用 `seg1-backyard-ruin.png`。**
- 第二～五段還沒畫，**先用同一張當佔位**，並在畫面上**明確標示是佔位**
  （例如關卡摘要區一行小字），不要假裝那是那一段的地景。
- 地景要能**垂直捲動**跟著地圖走。視差可以做，但**節點與路線不可以跟地景脫節**
  （玩家不能覺得節點在地景上滑動）。

### 節點母題
從 `icons-sheet.png` **確定性裁切**四格（寫成腳本，不要手動切），

**不要重畫、不要改色、不要加濾鏡。**

### 單檔自包含（這條不可以破）
`map20.html` 必須**維持單檔自包含**，`file://` 直接開就能跑，不外連任何資源。
圖以 **WebP data URI 內嵌**。

請另外交一支 `_art/holo-test/build_map20.py`：
從 `map-art/` 讀圖 → 壓成 WebP → 產出內嵌好的 `map20.html`。
**成品仍然是 `map20.html`**（沿用同一個檔名，不要改名）。

⚠ 檔案大小：整份 `map20.html` **≤ 2.5 MB**。超過就把 WebP 品質調低，

## 二、要修的三件事（我第一輪複驗記下來的）

### 修一：兩個面積指標貼著下限

第一輪實測：導軌占非卡片 UI **65.96／66.36／65.77%**（門檻 65～85%）、
紋理 **12.99／12.66／12.85%**（門檻 12～22%）。
三個尺寸都落在下限上方 1% 以內——這通常是**調到剛好過門檻**，不是設計的自然落點。

**這一輪要求落在帶寬中段**：導軌 **70～80%**、紋理 **14～19%**。
如果你認為這個版式的自然值就在下限、拉到中段反而更差，
**寫在回報裡說理由並附圖**，不要硬湊——但要說清楚。

### 修一之二：加了地景之後有一組新門檻要量（`PLAN-2.0-visual-C.md` 第五節）

| 項目 | 地圖常態 |
|---|---:|
| 地景可見面積／可用畫面 | **60～75%** |
| UI 覆蓋地景的面積／可用畫面 | **10～20%** |
| 已標定識別物的可見面積／可用畫面 | **15～25%** |

再加兩條硬的：
- **識別核心被不透明面板遮住 0～0%**
- 指定地標輪廓被 UI 遮住 **0～10%**

「已標定識別物」＝分叉大樹、白柵欄＋紅信箱、紅白格紋野餐布。
座標在 `docs/clicker/REPORT-map-art-seg1.md`，**用那三個包圍框當遮罩**。
地景可見面積要**扣掉不透明 UI 與遮蔽**；「UI 覆蓋」要**另計半透明面板實際壓在地景上的區域**，
不要讓半透明黑板鑽漏洞。

### 修二：磨損看起來像虛線裝飾，不像磨損

規格是「**磨損只發生在接縫與受力位置**」——方向對，但第一輪的呈現是導軌上的**等距短刻線**，
讀起來是裝飾紋不是被磨過的痕跡。

改法你自己判斷，但要滿足：
- **不是等距**。同一條接縫上的磨痕間距要不規則（但仍是**固定圖樣**，不要用亂數，
  每次載入必須一模一樣，不然沒辦法做決定性截圖）
- 磨痕要**貼著邊界／轉角／受壓側**，平面中央 0
- 交「磨損開 vs 關」並排圖；**並排沒差＝沒做到**
- 磨痕在指定空白樣區的灰階差維持 **6～14／255**（跟紋理占比是兩回事，兩個都要量）

### 修三：手機版

第一輪 390×844：下方面板吃掉約 **45%** 高度，王節點被面板邊緣切掉一半，
而且**段落選單整個消失**，玩家看不出自己在第幾段。

- 下方面板高度 **≤ 32% 視窗高**
- **任何節點都不可以被面板邊緣切到**（節點被裁切 0～0%）
- **段落指示必須在手機上可見**（至少「第 N 段 / 5」＋段名），
  不需要把整份選單搬回去
- 地景可見面積在手機仍要 **55～75%**（比桌面放寬 5 個百分點）
