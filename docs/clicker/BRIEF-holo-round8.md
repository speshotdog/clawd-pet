## 一、文字框回來，但層次要對（本輪重點）

> 「**我還是需要之前的文字框 只是文字是懸浮的 他們是前後關係
> 　圖繪背景是在最下層 拆出來的角色在文字框上層 名字文字最上層**」

第七輪把文字框整個拿掉了，**那是矯枉過正**。使用者要的不是「沒有框」，
而是**框、角色、文字三者有明確的前後關係**——角色會壓在框上面，像從卡面裡走出來。

**定案的 Z 順序（由後到前）：**

| 層 | 內容 |
|---|---|
| 1（最下） | **圖繪背景**（滿版景深卡的 background 層） |
| 2 | **文字框**（把第七輪移除的 `.face-plate` 那類底板加回來） |
| 3 | **拆出來的角色**（subject 層）——**壓在文字框上面** |
| 4（最上） | **名字文字**（與稀有度標） |

要點：

- 文字框**不是最上層**，所以角色的腳／尾焰／身體會自然地蓋過框的上緣，
  這正是使用者要的「前後關係」。**不要為了讓框完整而把角色壓回去。**
- 名字文字**永遠在最上層**，連角色都不能蓋住它（第六輪的
  `elementFromPoint` 驗證繼續套用，且要涵蓋「角色蓋住名字」這種新情況）。
- 文字框可以沿用第七輪之前的樣式，但既然角色會壓在上面，
  框的視覺重量可以再收斂一點（不要又變成擋住半張圖的黑條）。
- 名字與稀有度**維持置中**（第七輪已定案，偏差 <2px 的驗證保留）。
- 三層都要各自吃自己的 Z 位移與視差，前後關係在傾斜時要**看得出來**
  ——這是使用者說的「文字是懸浮的」。

⚠ **三種卡型要分別處理，不要一套套到底：**

- `depth`（滿版景深卡，有 subject／background 兩層）：完全照上表四層。
- `flat`（平面滿版卡，例如滅世珍獸，**沒有拆出來的角色層**）：
  沒有第 3 層可用，所以是 背景圖 → 文字框 → 名字。
  **這件事要在 README 說明**，不要假裝它也有角色浮出來。
- `framed`（去背卡框卡）：維持舊版樣式不更新（使用者已定案，當識別）。
