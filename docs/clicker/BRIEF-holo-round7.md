## 一、使用者實玩回饋（原話，本輪最高優先）

> 「**我要的是字體比圖層高　不是字體與他的框都在圖上面
> 　卡片名稱跟品質都要置中　全修正**」
> （附圖：火箭狗滿版卡，底部一整條不透明黑色銘牌壓在圖上，名字還偏右）

### 1. 拿掉那條不透明銘牌

前幾輪把「名字要在圖上面」實作成「**整塊銘牌蓋在圖上**」——那是誤解。
使用者要的是**文字本身浮在圖之上**，不是多一個擋住畫面的黑色橫條。

- **移除 `.face-plate` 那種不透明的實心橫幅**（現在是 `linear-gradient(#161b26f7,#111821fc)` 加邊框，
  幾乎全不透明，把滿版圖的底部整條吃掉）。
- 名字與稀有度**直接浮在畫面上**，讓圖一路鋪到卡的底部。
- **可讀性要靠文字自己**：描邊、投影、外發光、或**極輕微的漸層柔化**
  （由下往上淡出的 scrim，上緣完全透明）。
  ⚠ 那個柔化**不能變成另一個看得出邊界的方塊**——沒有硬邊、沒有框線、沒有實心底。
  判準：遮住的畫面要仍然看得見，只是被壓暗一點。
- 這一條對三種卡型都適用；去背卡框卡若原本就有底板，維持它原本的樣式即可
  （使用者已定案舊卡面不更新），**但滿版卡與平面滿版卡一定要照做**。

### 2. 名稱與品質都要置中

- **卡名與稀有度標都對齊卡片的水平中心。**
- 現在名字被寶石往右推，看起來是歪的。
  → **寶石不可以影響置中**。名字的置中基準是卡片，不是「扣掉寶石之後剩下的空間」。
- 這條要納入排版驗證：量名字矩形與稀有度矩形的中心，
  與卡片中心的水平偏差要小於一個很小的門檻（例如 2px），所有卡都要過。

## 二、寶石：換位置，並加上「看得見」的機器驗證

**這是連續第三輪失敗。** 第四輪立體版看不見、第五輪回到舊版方向仍看不見、
第六輪改平面還是一團融進深色底的暗塊。三輪都是「規格照做、視覺失敗」。

現在銘牌要拿掉了，寶石原本的位置也不存在了，一併重做：

1. **換版位。** 因為名字必須置中，寶石不能再擠在名字旁邊。做兩個版位並排讓使用者挑：
   - (a) **卡面右上角**（或左上角）——遠離名字，不影響置中
   - (b) **做進卡框本身**——例如框的上緣或一角開個缺口把寶石鑲進去
   兩個都做出來，用切換鈕讓使用者選。
2. **加一條對比度斷言（本輪重點）。** 把「看不看得見」變成機器可驗的數字：
   - 用 Playwright 截圖，取寶石的矩形區域與它周圍一圈的背景區域，
     算兩者的平均亮度差／色差，**低於門檻直接判定失敗**。
   - 門檻自己訂一個合理值並寫在 README，但要能真正擋掉「暗到融進背景」這種結果。
   - 五個稀有度都要過，五階並排區也要過（**不准為了塞下而縮小到看不見**）。
   - 這條驗證跟既有的間距驗證、名字疊層驗證並列顯示。
3. 形狀維持使用者定案的**平面菱形**（舊版 `src/gacha-card.css` `.face-gem` 那個方向），
   不要再做立體。

## 三、第三種卡型：平面滿版卡（使用者提案）

> 「**滅世珍獸 這種有背景但拆不出前後關係的　直接做平的滿版圖
> 　然後讓卡面有反光 光暈等等的效果**」

**採納。** 滅世珍獸的城市與角色同一片色調拆不開（前幾輪 README 都寫「尚未拆出角色」）。

卡型變三種，**要做成資料驅動的欄位**（例如 `art.kind: 'depth' | 'flat' | 'framed'`），
不要靠卡 id 寫死；以後新卡只要標欄位，也接得上精裝池「按卡池分檔次」的需求。

| 卡型 | 條件 | 做法 |
|---|---|---|
| **滿版景深卡** | 主體與背景拆得開 | 兩層沿 Z 推開做視差（四張場景卡） |
| **平面滿版卡** ← 新增 | 有背景但拆不出前後關係 | 整張平鋪、**不做圖內視差**；景深只發生在「卡片本身傾斜」，箔面／反光／光暈／光斑照常吃在卡面 |
| **去背卡框卡** | 單一角色去背 PNG | 維持舊版樣式不更新（使用者定案，當識別） |

- 平面滿版卡**不需要 GrabCut、不需要補底**，所以沒有暈邊、拉抹、接縫。
- 但**不能看起來像「忘記做景深」**：既然圖是平的，就要靠卡面材質補回質感
  （箔面流動、光斑、鍍膜反光、外圈光暈、邊緣高光）。賣點是「一張印得很好的大圖」。
- 目前屬於這型：**滅世珍獸**、**玩物就玩物**。
- 展示頁要能**並排比較**同一張滅世珍獸的「現在的假景深」與「新的平面滿版＋卡面材質」。
