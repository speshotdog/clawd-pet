# 我的複驗（第一輪地圖）

日期：2026-09-10。codex 自報 **160 PASS／1 FAIL**，唯一 FAIL 是 `cooldown.hidden_state`。

## 一、那一條 FAIL 我用更嚴格的方法驗過了 → **PASS**

codex 卡住的原因是真的：headless Chromium 不論怎麼弄，`document.visibilityState`
都回報 `visible`，所以它**不能宣稱**通過隱藏分頁測試。它沒有偽造事件，判 FAIL 是對的。

但「切分頁冷卻會不會停」這件事不必靠 visibilityState 來證。
最壞情況是**分頁被完全節流、計時器一次都沒跑**。所以我直接把計時器殺光：

```
before            冷卻 03:00
殺光所有 timer +6s  冷卻 03:00   ← 畫面停住，證明 ticker 真的死了
dispatch visibilitychange  冷卻 02:54
```

**剩餘秒數減少 6 秒。** 計時器完全沒跑的 6 秒照樣被算進去
→ 冷卻讀的是真實時鐘，不是累加器。

程式碼也對得上：`cooldowns[i] = Date.now()+180000`，剩餘 = `(cooldowns[i]-Date.now())/1000`，
`setInterval(tick,1000)` 只負責重繪，另外綁了 `visibilitychange → tick` 讓回來時立刻更新。
**沒有引用 `activeNow()` 那類可見性感知時鐘。**

腳本：`scratchpad/verify_cooldown.py`（一次性複驗，未入版控）。
