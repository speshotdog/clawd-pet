- 卡寬 102px、卡高 143px
- **卡名 8.4px，稀有度 9px** —— 稀有度比卡名還大
- 寶石 `--gem-fs` 7.74px
- 圖窗 `.art-media` 是 `x .064 / w .872 / h .792`
  （凍結規格是 `inset: 1.7% 2.4% 3.3%`，也就是 `x .024 / w .952`）
- **`.face-text` 是 null** —— 這個原型的卡把名字放在 `.face-plate` 裡，
  沒有走凍結規格說的「名字放 `.face-text`」
- 文字框 `x .038 / y .808 / w .924 / h .164`（這個跟展示頁一致）

我自己看到的兩個嫌疑：
1. 稀有度字級我照使用者要求 ×1.5（`RARITY_SHARE` 9/290 → 13.5/290），

   102px 卡算出來是 4.7px，被下限拉到 9px，於是超過卡名的 8.4px。
2. `build_deluxe_b.py` 的 `makeFace()` 是這個原型自己寫的一套 DOM，
   沒有跟著第十八～二十一輪的凍結規格更新（`.face-text`、圖窗 inset、Z 值）。
