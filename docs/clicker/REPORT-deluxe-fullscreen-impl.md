## 使用者裁決

十連結果十張同屏，沒有分頁。橫式使用 5 欄 × 2 列，窄直式使用 2 欄 × 5 列；直式列高不足時改為每格「左卡圖、右標籤」，保留全卡面並讓名稱使用更多橫向空間。尺寸依實際舞台重新計算，不把整頁等比縮小。

外置完整卡名為 16 CSS px、稀有度 14 CSS px，不截斷、不靠 hover 放大。卡內名字仍按既定卡寬比例。點任一卡片進入同頁大圖，可用按鈕或左右方向鍵換張；回總覽恢復原卡焦點。按鈕最小 44 × 44 CSS px。

精裝池沒有保底。單抽、五連、十連共用相同獨立抽樣函式，不修改抽出的階級、不替换十連尾張。入口與機率頁標明試抽機率、券價未定案；機率依 brief 設為神話 0.5%、傳說 4%、史詩 15%、精良 40%、普通 40.5%。

## 已實作內容

- 整頁深藍收藏襯紙、靜態偏斜封套、撕封紙邊與沿切口飛出的六片碎紙，沒有持續漂浮或背景旋轉。
- 普通翻揭、精良右下扣印、史詩短刷、傳說落印與金刷、神話三層彩紙裂開。沒有逐卡白閃或徑向光束。
- 依整包最高階級、原抽序第一張決定唯一完整高潮；其他高階卡使用局部短版。不在開包或未揭序號提前顯示階級。
- 預設逐張，可切自動、暫停、選未揭序號、提前下一張、跳過至全部結果。重看已揭卡不重播高潮。
- 完整高潮有安靜區；撕封引音早 40ms、翻卡摩擦與高階引音早 50ms，揭曉衝擊與正面／真名呈現同一回呼觸發。屬排程設計，尚未量測實機聲畫延遲。
- 本地複製並改寫 `gacha-audio.js` 的 lazy AudioContext、包絡、振盪器、濾波噪音與 scope 原理。短回聲為 scope 內 173／251ms delay，不引用原檔，不載入音效檔。
- 靜音與音量零在共同輸出 bus 上以 25ms 收至零，dry／wet 共用路徑；跳過、返回、失焦清掉時間軸、動畫及音源，scope 30ms 淡出。取消後不補播。
- 收下只入冊一次，全批縮向封套、封口一次。扣券與入冊不依賴動畫完成；快速返回或切換分頁不會重複入冊。
- 本原型使用獨立 localStorage key `deluxe-full-prototype-v1` 保存券數、未收結果與典藏冊，不讀寫遊戲存檔。瀏覽器禁止 file:// 儲存時，仍保留本頁記憶體內結果。返回入口有「繼續這包」；券不足可補充試抽券。
- 素材預解碼；載入失敗時仍保留已固定結果，可依名稱、階級收下。減少動態模式取消翻轉、位移、紙裂，縮短揭曉且保留操作。

## 卡面與資料來源

產生器擷取 `demo.html` 的 style，跳過 `baseline-css` template，並嵌入 `#mask-data`。沿用既有卡框、箔紋、寶石、文字框與字效；傳說維持 `#fff45c`，神話維持跟隨 `--phase` 的 conic 彩虹，靜止不循環。

43 張有美術素材的卡直接讀 `src/gacha-pool.js` 的 CATALOG，名稱不手打、不從檔名推。四張場景不在 CATALOG，改讀 HANDOFF 六之三的定案表格，避開 demo 舊資料中的「玕面探索者」錯字，使用「玥面探索者」。共 47 張；未加入缺圖的 14 張角色／emoji。

去背卡使用既有 `art/` 裁切圖。圖像矩形在「卡頂至文字框上緣」的圖窗中心排版；subject foil 依 manifest 的來源尺寸與 bbox 裁切到相同座標，再與圖像同步 contain。場景前後層保留共同構圖，不各自做 bbox 置中。三種卡型採同一文字安全區，名字與寶石分開，長名換行時文字框可上增至 22%。

## 留給瀏覽器驗收

本輪沒有宣稱完成畫面或聽感驗收。請以 960×640、560×900、360×900 等視口確認十張完整同屏、外置字級、觸控區、字形不撞框、圖窗中心偏差 ≤ 2px；並確認 console／request、靜音尾音、跳過後無补播，以及演出結束後 `document.getAnimations()` 無殘留。

驗收可用：

- `window.__draw(10)` 或 `window.deluxe.draw(10)`：純抽樣，不扣券。
- `window.deluxe.snapshot()`：目前畫面、券數、pending、已收數、忙碌狀態、時間軸／動畫數、音效狀態。
- `window.deluxe.catalog`：原型可用 47 張卡的資料。
