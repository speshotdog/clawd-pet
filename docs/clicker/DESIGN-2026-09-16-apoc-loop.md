# 2.0 輪迴模式提案（2026-09-16，使用者：「打完全 BOSS 後要輪迴模式怎麼增設，可以輪迴 2.0 的地圖、難度持續調整」）

## 〇、現在已經有的（先講清楚，不要重做一套）
全線通行（第 20 站）後會跳「全線通行面板」，裡面有兩件事：
- **重走廢土**（`replay()`）：保留收藏，進度／末世金幣／訓練歸零重走 20 站。第 1 圈敵人血 ×10、之後每圈 ×1.1；戰力每圈 +25%；上限 10 圈；每圈 +4 印記（印記重設計的來源之一）；五隻王的首勝粉塵每圈重算。
- **無盡模式**（`setEndless()`）：第 21 站起一直往下打到第 100 站，王四種機制輪流，記最遠站數 `endlessBest`。
- 徽章：重走 1 圈／5 圈／無盡 +10 站。全破後場上常駐第 18 站（回顧）。

問題不在「沒有」，在**它沒有身分**：玩家按下「重走廢土」只看到一行字「下一圈敵人血 ×11、戰力 ×1.25」，然後一模一樣的 20 站再走一次。
沒有新東西看、沒有選擇、沒有累積感。所以這份提案是把重走升級成「輪迴」，不是加第三套。

## 一、設計目標
1. 每一圈**看得出不一樣**（不是只有數字變大）。
2. 難度「持續調整」＝有一條會漲的線（圈數）＋有一個玩家能拉的旋鈕（變異），太難時有退路，不會卡死。
3. **不動兩週日曆**：印記來源不加、上限不動（每圈 4 枚、10 圈封頂已經在鐵律內）；輪迴的獎勵走「粉塵／金幣／外觀／紀錄」，不走印記。
4. 有終點：10 圈到頂之後接無盡，無盡是「排行榜式」的目標，不是養成。

## 二、機制

### 1. 圈＝難度層，變異＝這一圈的長相
每圈開始時從**變異池**抽 2 個（第 1 圈 1 個、第 5 圈起 3 個），整圈生效，地圖與戰鬥畫面都掛著：

| 變異 | 效果 | 反制 |
|---|---|---|
| 厚甲 | 王血再 ×1.3 | 破防型技能 |
| 倒數 | 王關期限 60 → 45 秒 | 開封＋加訓連放 |
| 狗海 | 灰狼犬的狗群 5 → 8 隻、再來 4 次 | 放置狂熱（放置也打狗） |
| 硬殼 | 貼紙羊多一層殼（血 25% 也長） | 點擊型 |
| 亂拍 | 扛槌兔節拍視窗 200 → 140ms | 加訓（不吃節拍）＋重整 |
| 反鎖 | 技能冷卻 ×1.25 | 重整型 |
| 缺糧 | 站獎金 ×0.7 | 撿金幣型 |
| 荒地 | 放置傷害 ×0.5 | 開封型、手動 |
| 豐收（正向） | 站獎金 ×1.5、掉券率 ×2 | — |
| 回聲（正向） | 技能冷卻 ×0.8 | — |

- 池子裡正向：負向 = 2：8，抽到正向就是「這圈好走」的運氣，讓每圈有期待感。
- **重抽一次**要花末世金幣（這圈起始金幣是 0，所以是用上一圈剩的錢——給「打完別急著按重走」一個理由：上一圈的錢帶進來一半當「輪迴盤纏」）。
- 變異對應到六型技能的反制，推薦組合頁在輪迴中會多一組「這一圈的解法」（用現成的 role 模板）。

### 2. 難度曲線
- 血：維持現在 ×10 × 1.1^(N−1)；戰力 +25%/圈維持。
- 變異數：1 → 2（第 2 圈）→ 3（第 5 圈）。
- **退路**：同一隻王連敗 3 次，面板出現「換一個變異」（免費一次／圈）；再連敗 3 次出現「這一圈少一個變異」。目的：難度會自己往下修到玩家打得過，不會卡在第 7 圈永遠出不去。

### 3. 每圈的獎勵（都不是印記）
- 五王首勝粉塵每圈重算（已有）。
- 圈末結算：**輪迴寶箱**——這一圈用時越短、變異越多，開出的萬用粉塵越多（上限每圈 3 顆，10 圈 30 顆＝一張卡滿養的 22 顆再多一點；這是全滿養兩週線內的量，要過模擬）。
- 圈數紀錄：每圈用時、變異組合、失敗次數，寫進戰績頁「輪迴紀錄」表。
- 第 3／6／10 圈解鎖三個受擊特效配色（末世商店現有的 HIT_FX 機制，純外觀）。

### 4. 10 圈之後
- 「重走廢土」變成「無盡」入口：無盡的站數 21～100 沿用，但**變異每 10 站加一個**（用同一個池），最遠站數就是排行紀錄。
- 10 圈後的每一圈仍可以再走（練習／刷粉塵 3 顆上限不變），只是不再給印記（已是現況）。

## 三、UI

### 1. 頂列（戰鬥畫面右上）
現在：「戰力 744・每秒 7.4・印記 40」。
加一行：**「第 3 圈 ・ 厚甲／倒數」**——變異用兩個小藥丸，指到／點開有說明。第 0 圈（還沒全破）不顯示。

### 2. 地圖
- 標題「廢土地圖」旁加圈數徽章「第 N 圈」。
- 地圖上方一條橫幅：這一圈的變異藥丸（跟頂列同一組），右邊「重抽（N 金幣）」。
- 王站的節點上疊小圖示（厚甲＝盾、倒數＝時鐘…），點站時說明面板寫「這一圈：王血 ×1.3、期限 45 秒」。

### 3. 全線通行面板（重做）
現在是一段字＋兩顆鍵。改成三張卡並排（手機直式改直排）：
```

│ 變異 ×2（進去才抽）        │ │                   │ │                   │
│ 盤纏：帶 4.2 萬金幣進去    │ │                   │ │                   │
│ [ 開始第 4 圈 ]            │ │ [ 進入無盡 ]       │ │ [ 關閉 ]          │
└───────────────────────────┘ └───────────────────┘ └───────────────────┘
```

按「開始第 4 圈」→ 變異抽選動畫（三張牌翻開兩張）→ 顯示「這一圈的解法：推薦組合『破防流』」→ 進地圖。

### 4. 王關失敗面板
現有的失敗結算加一行：連敗計數「這隻王連敗 2 次」；到 3 次多一顆鍵「換一個變異（這圈免費 1 次）」。

### 5. 戰績頁
新分頁「輪迴紀錄」：表格 圈數｜變異｜用時｜王關失敗｜寶箱粉塵；底下「無盡最遠 第 N 站」。

### 6. 圈末結算
打完第 20 站彈「第 N 圈完成」：用時、變異、寶箱開出 N 顆萬用粉塵（動畫）、解鎖的配色，然後才進全線通行面板。
