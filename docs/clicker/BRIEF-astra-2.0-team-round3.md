## 二、接上黑角判準（使用者今天特別交代的雷）

工法在 `docs/clicker/METHOD-card-face.md` 第三節。成因是
**方角圖層 ＋ `mix-blend-mode:screen` ＋ 獨立 3D 合成層**，圓角外沒有背景可混就吐出純黑。

`_art/holo-test/check_card_corners.py` 已經寫好並雙向驗證過，**接進 `check_team20.py`**：

- 對 **編隊畫面** 與 **地圖畫面**（地圖沒有卡就跳過）各跑一次
- **每次都要跑負控制**（注入已知壞寫法，判準必須變紅）。
  判準沒有鑑別力的話，綠燈不代表任何事
- 判紅條件：該角 `≤ max(4, 在地中位×0.35)` 的像素占比 **≥5%** **且** 該角最暗 **≤6**

### ⚠ 負控制必須注進 shadow root，注在頁面上是無效的

**你把卡面放進了 shadow root**（11 個 host：`span.overview-face`、`div.card-host`）。
我第一次把壞寫法注在頁面層，`::after` 的 computed `content` 一直是 `none`、
截圖像素差 **0.000%**——**注了等於沒注，而我差點把它當成「編隊畫面沒有這個問題」。**

正確作法（實測會讓像素差變成 49.2%）：

```js
for (const h of [...document.querySelectorAll('*')].filter(e => e.shadowRoot)) {
  const s = document.createElement('style');
  s.textContent = '.card-face{isolation:isolate}.card-face::after{content:"";position:absolute;inset:0;background:#000;mix-blend-mode:screen;transform:translateZ(2px);pointer-events:none}';
  h.shadowRoot.appendChild(s);
}
```

**注入後要先確認 `getComputedStyle(el,"::after").content === '""'` 再開始量。**
