## 切入實際時間軸

所有切入時間集中在 `clicker-cutin.js` 頂部的 `T`；時間單位為 ms。`t=0` 是技能成功寫入存檔並啟動演出。若存檔失敗，不播切入。

| 時間 | 實際行為 |
| --- | --- |
| 0–80 | 立即發動效果、扣用技能與開始冷卻。角色／包裝／粒子／浮字凍結。960×640 全幅深色壓暗 82%，漫畫網點 12%。110→70Hz、140ms、gain .12。 |
| 80–260 | 技能色放射線 scale 1.6→1；粗環 2.2→.9 消失。舞台上下各56px letterbox 帶2px奶白內線。260px徑向亮區定位珍母／舞台中央。 |
| 260–400 | 520×300 面板從左撞入；珍母從右撞入。80ms達超衝12px、60ms回彈。背板技能色、18% multiply斜紋、4px墨色描邊、skewX(-6deg)。水平拖線120ms。 |
| 300–400 | 本尊 SVG 特寫高340px，頭超出面板；晚40ms進場，滑60px並由1.08縮回1。背後淺色墨漬。 |
| 300–700 | 400ms招牌rig：玥玥掃尾、膠布揮刀臂、珍母觸手張開；使用共用樞紐與擺幅倍率，中間眨眼一次。 |
| 340–490 | 胸前impact，90ms由.4放大1.15、60ms消失；舞台50ms三格抖動。白噪音掃頻3k→600Hz、60ms、gain .08，另加30ms啪聲gain .15。 |
| 520–640 | 奶白乾刷橫幅從左刷出120ms。 |
| 640–720 | 48px技能名scale1.3→1，副標18px由下8px淡入。珍母分行為「這個頭／我收下了」，避免落單字。 |
| 720–820 | 右下紅色雙圈章scale1.6→1、rotate(-12deg)，顯示×2／×10／發動；再次50ms短震與180Hz、60ms、gain .1。 |

| 1050–1350 | 珍母另接300ms宿主頭像合體；落位再出小impact。 |

切入不可按 Escape／重複技能跳過，也不能中途開招募或名冊。`#tap` 不設 inert、不攔點擊，沿用每秒最多8次的既有規則，效果次數立即扣除，切入期間不生成新粒子或浮字。視窗隱藏／關閉時清理演出，已結算收益不回滾；回來依現有結算流程恢復。

減少動態保留同長度的壓暗、角色面板淡入淡出、技能名與副標；不放速度線、圓環、letterbox、撞入、rig、impact、印章或震動。音效仍受靜音設定控制。

共用粒子沒有 pause API，因此在 clicker 的 spawn wrapper 中凍結位置與壽命更新；未改共用引擎。既有 Web Animations pause/play，舞台 rAF 在 frozen 時不寫 transform。切入 PNG 在可操作前預載／decode，避免第一次使用時才開始載圖。

## 還差什麼（誠實）

第三輪提出的素材筆觸、字型、技能槽擁擠、五連小字、缺少技能釋放與測試分頁互相覆寫均已實作處理。但「第一眼無法分辨獨立小品或上市遊戲」是美術與實機體驗判斷，不能由測試全綠保證。

本輪未做原生Tauri/WebView2、不同DPI與實體喇叭的完整驗收；瀏覽器截圖與程式參數不等於完成原生音畫同步、低階機幀率和真實音量混音簽核。其餘九位技能按規格維持後續開放，沒有擅自設計效果；本次切入已有稀有度配色支援。
