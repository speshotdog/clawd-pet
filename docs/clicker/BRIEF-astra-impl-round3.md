## 1. 點擊粒子跟著滑鼠

- 滑鼠點擊：碎紙從**指標位置**噴出（`#tap` 的 pointer 事件拿 `clientX/Y`，換算成全畫面 960×640 座標；注意 `#zoomer` 的縮放要除回去）。鍵盤 Space／Enter 觸發時退回包裝撕口錨點。
- 浮字（+N）也從指標位置上方 12px 升起，跟粒子同落點。
- 配方維持我上輪改過的量（普通 8／連點 12／重擊 18＋光痕，碎紙 10–22px、噴高 260–330px/s、壽命 .55–1s、翻面暗色）。**不要縮小。** 可以再加：連點第 3 下起每擊多一顆金色小閃；重擊多一圈 sprite 3 的環（r 36→ 90，life .25，`lighter`）。
- 包裝本身的回饋（彈一下、切狀態、撕開）不變，仍在包裝上。

## 4. 數字表現（參考 Cookie Clicker／Egg, Inc.／Tap Titans 的做法）

- **餘額滾動**：餘額不直接跳到新值，用 tween（每幀朝目標逼近 25%，>1000 差距時 300ms 內補完；`tabular-nums` 避免抖動）。放置時 1Hz 結算仍走同一 tween。
- **增加時的彈跳**：每次餘額增加，金幣牌上的數字 `scale(1→1.12→1)` 140ms、金幣圖 `rotate(-8°→0)`；連點狀態下不重排隊列，只重設當前動畫。
- **每次／每秒速率**：升級後數值變化時，新值從下方 6px 滑入、舊值淡出（180ms），跟第一版定案的「升級數值上推」合併。
- **消費時**：餘額往下 tween、數字短暫變成 `#C9686B` 再回黑（200ms）；價格票券在購買當下 `scale(.96)` 一拍。
- **浮字**：`+N` 跟指標同落點，加輕微的水平隨機 ±10px 與 60ms 內 `scale(.6→1)` 的彈出，再上升淡出；連點第 3 下起字級 20→22px 並偏黃 `#E9B94E`；重擊 26px 帶一次 `rotate(-6°→0)`。
- **大數格式**：≥10,000 顯示 `1.23萬`、≥1億 `1.2億`（中文單位，遊戲是繁中）；詳細值放 `title`。經濟純邏輯不動，只改顯示層 `format`。
- **量尺**：拆包量尺填充也用 tween，跨包時先填滿再歸零。
- 這些全部是「有變化才動」，閒置沒有任何常駐動畫。
