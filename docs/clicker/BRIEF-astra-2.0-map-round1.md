## 一、C＝災後搶修工作盤：這一輪要建立的元件

規格全文在 `PLAN-2.0-visual-C.md` 第一節①。摘要（**以那份為準，不要憑印象**）：

- **底**：煤灰 `#242723`、氧化灰綠 `#373D35`、骨白 `#E5E3D6`
- **紋理**：只有面板帶靜態刮痕，**自製固定圖樣的 SVG**，不要搬箔紋、不要用亂數
- **字**：黑體；說明 13～15px／正文 16～18px／標題 24～28px；
  正文字距 0～.02em、標題 .04～.08em；**數字等寬**
- **控制**：圓角 **0～2px**、單線 1～2px；
  **按下改凹槽明暗＋側邊實心標，不下沉、不彈跳**（這是跟 1.0 分開的關鍵——1.0 是 4px 硬陰影＋按下位移 3px）
- **結構**：共用分隔導軌；面板間距 12～20px、內距 16～24px
- **圖示**：平頭線段與實心缺口，線寬 1.5～2px，圖示盒 20～24px

**磨損的規則（這是這套語言的靈魂，不要做成滿版做舊）**：
**磨損只發生在接縫與受力位置**——導軌交界、槽口邊緣、按鈕受壓側。
平面中央不要加紋理。

## 二、地圖

### 結構
五段，每段 **3 個一般關 ＋ 1 個王關** ＝ **20 關**（先做下限那組）。

| 段 | 地景名（文字，這一輪不做美術）| 王 | 機制標籤 |
|---|---|---|---|
| 一 | 後院草地・廢墟 | 灰狼犬 | 召喚小怪 |
| 二 | 補給線 | 貼紙羊 | 護盾層 |
| 三 | 夜市攤・廢墟 | 扛槌兔 | 節奏 |
| 四 | 冷藏庫深處 | 雞頭合成怪 | 順序 |
| 五 | 滅世都市 | 真・滅世珍獸 | 前四種輪播 |

**每段最後一個一般關是「預告關」**，只加視覺標記，不加機制：
①草地被踩平的路徑 ②纏著撕不斷的包裝膜 ③**地面固定間隔的槌痕（間隔＝之後的拍子）** ④對不上任何動物的腳印 ⑤街道不該有的弧度。

### 版式
**垂直捲動、單一路線、局部左右偏移**。偏移只是構圖，**不可以看起來像岔路**。
桌面右側放關卡摘要，手機放底部。

| 元素 | 門檻（上下限成對，全部要在 `check_map20.py` 量出來）|
|---|---|
| 普通節點 | 本體 44～60px；相鄰中心縱距 104～144px、橫向偏移 24～56px；**靜止位移 0**；輪廓與底色對比 3～5:1 |
| 路線 | 線寬 2～3px；已走 alpha .65～.80、未走 .22～.34；**分岔 0 處** |
| 當前位置 | 切角括框距本體 6～10px；對比 5～7:1；切換 160～220ms、**位移 0** |
| 已通關 | **保留站名** ＋ 勾號 14～18px；圖形對比 3～4.5:1；標籤對比 4.5～7:1 |
| 未解鎖 | 空心節點＋鎖＋前置站名；圖形 alpha .30～.42；標籤對比 4.5～7:1；**不顯示可挑戰按鈕** |
| 王節點 | **寬幅閘口剪影，路線從中央穿過**；寬為普通節點的 1.4～1.8 倍；外形對比 4～6:1；**不靠紅色辨識** |
| 推進一格 | 落勾 120～160ms → 連線填滿 240～320ms → 括框移位 160～220ms；峰值線 alpha .78～.90 |

### 鏡頭規則
新節點**已在視野內就不捲動**；被遮住才移動，單次 **12～28% 視窗高**、**280～380ms**，
**不跳到畫面正中央**（會遮斷上下文）。

### 王關冷卻 ⚠ 這條一定要照做
**失敗後 3 分鐘冷卻。冷卻必須用獨立的到期時間戳（`Date.now() + 180000`）決定，
不可以用 `ceremony.js` 的 `activeNow()` 那種「可見性感知時鐘」**——
`pauseTimers()` 會在分頁隱藏時凍住它，玩家切到別的分頁冷卻就停了。

冷卻中的王節點**要顯示剩餘時間**（等寬數字、每秒更新），不能只變灰。
**任務測試中「不能返回或沒有下一步說明」的死路數量必須是 0。**

### 減少動態
`prefers-reduced-motion: reduce` 下：狀態切換 100～160ms、**追蹤移動 0px**，
但**線型、文字、形狀的差異必須保留**（不能靠動畫才分得出狀態）。

## 三、測試鉤子（驗收要用，請一定做）

用 URL query 直接設定畫面狀態，讓截圖可重現：

- `?progress=N` —— 已通關到第 N 關（0～20）
- `?cooldown=SEC` —— 目前段的王關冷卻剩餘秒數
- `?motion=off` —— 等同 reduced-motion
- `?ui=off` —— **關掉所有 C 語言的面板／導軌／紋理，只留節點與路線**
  （這是「開 vs 關」並排圖的「關」那一張，**空間要保留、不能重排**）

## 四、驗收（`check_map20.py` 要跑出來的）

1. 上面第二節那張表的**每一個數值**，量出來寫進 JSON，並標 PASS／FAIL。
2. **C 語言占比**：共用導軌分區占非卡片 UI 面積 **65～85%**；
   獨立漂浮、帶完整外框的面板 **0～15%**。
3. **紋理節制**：有紋理的表面占非卡片 UI **12～22%**；
   紋理開關在指定空白樣區的平均灰階差 **6～14／255**。
4. **並排圖**：`?ui=off` vs 正常，1440×900／1024×768／390×844 三個尺寸各一組。
   ⚠ 手機那組**不准縮成縮圖判斷**，交原尺寸。
5. **移除色彩後仍成立**：把兩張圖轉灰階，C 的結構仍可辨（交灰階圖，我人工判）。
6. **冷卻不被分頁隱藏影響**：用 playwright 讓分頁隱藏 5 秒再回來，
   剩餘秒數必須**照實減少 5 秒**（誤差 ±1 秒）。這條 FAIL 的話整輪不算完成。
7. 三次取平均的只有時間類；**跨機器的絕對值不要拿來比**。
